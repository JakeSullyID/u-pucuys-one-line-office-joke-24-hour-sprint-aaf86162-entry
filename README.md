# One-Line Office Joke: 24-Hour Sprint

This entry is a lightweight Node 22 program that outputs a deterministic, self-contained one-line office joke into `entry.txt` with zero dependencies and no network access required. Delivering razor-sharp wit in a single restriction-bound sentence is the ultimate test of comedic efficiency where every character truly matters.

## How to Run

Execute the program using Node.js:

```bash
node main.ts
```

You can optionally specify a custom output directory by setting the `MAKEFUN_OUTPUT_DIR` environment variable:

```bash
MAKEFUN_OUTPUT_DIR=./dist node main.ts
```
